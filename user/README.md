# user/

Local, personal override/preference layer for people developing *this* toolkit repo — not to be confused with the `user` **install scope** (`bin/toolkit --scope=user`, which installs to `~/.copilot`, `~/.claude`, `~/.gemini` on someone's machine).

Anything you drop in here besides this README is gitignored — it's a scratch space for trying out personal tweaks to agents/skills before proposing them for `global/`. Nothing here is read by `bin/toolkit` yet.
